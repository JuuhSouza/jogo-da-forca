# Jogo da Velha em vue
## Vue 3 + Vite

Estudo feito com o intuito de aprender e compreender mais sobre o sistema de props, feito com tutorial e implementação propria de melhorias.

Rodando o projeto:

git clone link do repo -> clonar o repo

git cd nome do arquivo -> entrar no arquivo

npm i -> instalar as dependencias do node

npm run dev -> rodar o projeto
